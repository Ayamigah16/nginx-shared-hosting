# Site 1 - Portfolio Website

## Theme
Professional portfolio website with purple/blue gradient theme

## Key Features
- Responsive design
- Animated hero section with floating circles
- Project showcase grid
- About section with statistics
- Contact information
- Smooth scroll navigation

## Color Scheme
- Primary: Indigo (#6366f1)
- Secondary: Purple (#8b5cf6)
- Accent: Pink (#ec4899)

## Purpose
Demonstrates a portfolio/personal website use case for virtual hosting
