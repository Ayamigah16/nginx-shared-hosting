# Site 2 - E-commerce Store

## Theme
Modern e-commerce store with orange/green color scheme

## Key Features
- Product catalog with grid layout
- Interactive "Add to Cart" buttons
- Feature highlights (shipping, security, etc.)
- Visual server architecture diagram
- Responsive product cards
- Smooth animations

## Color Scheme
- Primary: Orange (#f97316)
- Secondary: Green (#10b981)
- Accent: Yellow (#fbbf24)

## Purpose
Demonstrates an e-commerce website use case for virtual hosting
